**Why I created this project? 🤔**

I created this slack bot as a beginner project into javascript and slackbot development. I'm really happy how it ended up, and that I made the bot save rolls for each user.

**Features list 🎯**
<br>
1. 🐱 /yaknow-cat - Sends a random cat image.
2. 🙀 /yaknow-catfact - Sends a random cat fact.
3. 🤣 /yaknow-joke - Sends a random joke.
4. 🎲 /yaknow-roll - Rolls a random number between 1 and 1,000,000.
5. ☘️ /yaknow-leaderboard - Displays your best rolls (highest, lowest, if you've rolled 777)
6. 💻 /yaknow-help - Displays all current yaknow commands.
7. 🛜 /yaknow-ping - Check bot latency.

<br>

**About the feautures 😎**
<br>

I created Yaknow bot originally around a cat theme. If you run /yaknow-cat it shows a cat image off an api, and if you run /yaknow-catfact it sends a request to an api and gets a random cat fact! (example below)

<img width="1882" height="1004" alt="image" src="https://github.com/user-attachments/assets/8881dd08-00e4-4441-9ef7-319daabaa3c0" />

I'm not going to explain every other feature in detail, but I need to explain the roll commands. If you run /yaknow-roll it "rolls" a random number between 1 and a million. It then checks to see what number was rolled, and displays a custom message if you roll a lucky number. The script also checks to see if each role beats any of your personal records, and if so it saves it into a .json file that's organised by Slack IDs. Want to check your best roles? Run the /yaknow-roll-leaderboard command! It reads and fetches the data from the json file.
